# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub:

https://github.com/dhe-cruzer69/Prismx3/security/advisories/new

Do not open a public issue for a suspected vulnerability.

## Response

- Acknowledgement target: 72 hours
- Confirmed issues: a fix or mitigation on the default branch as soon as it is verified
- Coordinated disclosure after a fix is available

## Scope

This policy covers code, workflows, and configuration in `dhe-cruzer69/Prismx3`.
Third-party forks and upstream projects keep their own security policies.
